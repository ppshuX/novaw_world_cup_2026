## 二、球队档案（48支）

### A组

**墨西哥（Mexico，缩写 MEX，🇲🇽）**
- 小组：A组 | FIFA代码：MEX | 历史参赛：17次（含本次18次）
- 主教练：Javier Aguirre（哈维尔·阿吉雷，墨西哥籍）
- 代表球星：埃德松·阿尔瓦雷斯、圣地亚哥·希门尼斯、洛萨诺
- 东道主之一，揭幕战在阿兹特克体育场迎战南非，主场氛围是本届赛事最大看点之一。墨西哥历史上最好的世界杯成绩是1970年和1986年两次在本土打进八强，本届希望借助主场之利冲击更高目标。

**南非（South Africa，缩写 RSA，🇿🇦）**

- 主教练：Hugo Broos（雨果·布鲁斯，比利时籍）
- 代表球星：罗恩文·威廉姆斯、特博霍·莫科纳、珀西·陶
- 南非曾在2010年举办世界杯，成为首个非洲东道主。本次通过非洲区预选赛晋级，球队风格以身体对抗和速度著称，威廉姆斯是非洲最佳门将之一。

## 五、赛事规则

### 赛制说明

2026世界杯首次扩军至48支球队，采用全新的赛制：

**小组赛阶段（6月11日–6月28日）**
- 48支球队分为12个小组（A至L），每组4队
- 每队进行3场小组赛（单循环）
- 胜3分、平1分、负0分
- 排名先看积分，再依次比较：净胜球、进球数、相互战绩、公平竞赛积分、抽签

**淘汰赛晋级**
- 12个小组的前2名（24队）直接晋级32强
- 8个成绩最好的小组第三名也晋级32强
- 共32支球队进入淘汰赛阶段

**淘汰赛阶段**
- 32强 → 16强 → 8强 → 半决赛 → 三四名决赛 → 决赛
- 打平则进行30分钟加时赛
- 加时赛仍平则进行点球大战（每队5轮）
- 5轮后仍平则进入突然死亡式点球（一回合制）

### 加时赛与点球规则

- 常规时间90分钟（上下半场各45分钟，中间休息15分钟）
- 淘汰赛打平 → 加时赛30分钟（上下半场各15分钟，不休息）
- 加时赛仍平 → 点球大战
- 点球大战5轮后平 → 逐个加罚直至分出胜负

### 红黄牌处罚

- 累计2张黄牌 → 自动停赛1场
- 直接红牌 → 当场罚下 + 至少停赛1场
- 小组赛黄牌在16强结束后清零

### 球员参赛资格

- 每队最终名单最多26人（最少23人）
- 比赛日大名单最多23人，首发11人
- 每场可使用最多5个换人名额（3次换人窗口 + 中场休息）
